# Zenova Biosource

[![Website](https://img.shields.io/badge/website-zenovabiosource.com-12c0ba)](https://www.zenovabiosource.com)

Official website for **Zenova Biosource** — a supplier of laboratory, diagnostic and medical equipment serving hospitals, diagnostic laboratories, research institutes, medical colleges and government organizations across India.

**Live site:** https://www.zenovabiosource.com

## Tech Stack

- **Next.js 16** (App Router) with static site generation
- **React 19** + **TypeScript**
- **Tailwind CSS 4**
- **Framer Motion** animations
- Deployed on **Vercel** via git integration

## Features

- Product catalog across 8 categories with dedicated SEO category pages
- Services (installation, calibration, AMC/CMC, IQ/OQ/PQ validation, training)
- RFQ enquiry form
- Structured data (LocalBusiness, WebSite, BreadcrumbList, ItemList)
- Fully responsive, accessible, security headers enabled

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

| Command          | Description                          |
| ---------------- | ------------------------------------ |
| `npm run dev`    | Start development server             |
| `npm run build`  | Create an optimized production build |
| `npm run start`  | Start the production server          |
| `npm run lint`   | Run ESLint                           |
